# 1.1 界面设计

参考：[Apple DESIGN.md](https://getdesign.md/apple/design-md)。将其白色与浅灰底色、单一蓝色交互、清晰字体层级和留白用于 Windows 桌面工具；采用 Windows 系统字体。

原则：避免不必要的辅助标签与说明，让布局本身发挥解释作用。

- 顶部使用分段模式控件，主标题只表达实际输出。
- 两张设备卡片对应游戏耳机与日常音箱，卡片本身就是选择入口。
- 游戏列表仅常驻显示名称，程序路径按需通过提示显示。
- 偏好以三行控件呈现，附加说明移入悬停提示。
- 首次使用、离线和切换失败提供各自必要的反馈。
- 保存采用行内反馈，不再弹出重复确认。
- 使用原生 WinForms 与 GDI+ 绘制；没有浏览器引擎、第三方字体或新增运行时依赖。

验证：`test.ps1` 检查路由与配置；`test-ui.ps1` 检查设备选择验证、保存、延迟边界、游戏删除与搜索、控件边界及测试期间音频默认设备保持不变。
