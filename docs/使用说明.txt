轻音切换 · Light Audio Switch

解压后双击 LightAudioSwitch.exe。首次运行请自行选择游戏耳机与日常音箱，再保存。
关闭窗口后仍留在托盘运行；再次双击程序或托盘图标可打开设置。

默认规则：
已添加的游戏进程运行 → 耳机。
所有游戏退出 → 等待 3 秒 → 日常音箱。
WeGame、Steam 常驻不会触发。游戏挂后台时仍保持耳机。
已预置《三角洲行动》的游戏进程名，不预置个人设备或磁盘安装路径。

托盘菜单：自动切换、锁定耳机、锁定音箱、设置、退出。
手动锁定保持到选择“自动切换”；重启默认恢复自动。
退出停止控制，保留最后的输出设备。

设置中可以添加游戏 EXE 或从正在运行的程序添加游戏本体。
可设置 0～30 秒退出延迟、登录自启动、是否切换默认通信输出。
自启动仅使用当前用户 Run 项；移动程序后请重新保存自启动设置。
卸载前取消自启动并保存，再从托盘退出，最后删除文件夹。

需要蓝牙音箱时请先自行完成 Windows 配对和连接。
目标未连接时保留当前输出；重新配对导致 ID 变化时，刷新并重新选择。
程序不负责强制重连或唤醒蓝牙设备。

若声音未跟随：
把 Windows 音量混合器中的应用输出或应用自己的输出设为“默认”。
部分游戏在启动时固定设备，可在游戏内指定耳机，或启动前先手动锁定耳机。
游戏与浏览器同时运行时，跟随系统默认设备的浏览器也会进入耳机。
软件更改默认输出，不捕获、重新混合或强制迁移正在播放的音频流。
默认设备切换使用未公开 Windows COM 接口，系统更新后可能需要兼容修复。

配置和日志保存在程序文件夹中；不要把个人 config.json 或日志上传到公开仓库。
不联网、不上传数据、不修改麦克风或音量、不安装驱动、不注入游戏。
Windows 10 22H2 x64 已验证，Windows 11 尚未实机验证。
