# 验证范围

原型在 Windows 10 22H2 x64 上通过 47 项检查，包含策略与配置、真实设备切换、默认设备事件、受控进程生命周期、多进程重叠、手动锁定、离线目标、单实例与命令行通信。检查后恢复测试前的默认输出角色。

公开版移除个人设备自动匹配与个人游戏路径，提供可参数化的测试脚本。`test.ps1` 默认只运行不改变音频输出的检查；`-Hardware` 显式启用真实设备测试，并要求使用者提供设备名称。

边界：未登录或启动真实游戏，未验证实际抖音播放的音频流迁移；未测试 Windows 11；未验证长时间运行或所有蓝牙断连、休眠和驱动重装情形。登录自启动未在原型验证中实际开启。

性能参考仅来自原型的短时采样：工作集约 32 MiB，专用内存约 27 MiB；20 逻辑核电脑上约 15 秒采样的整机 CPU 占用约 0.02%。
